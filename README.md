# 🎮 Tic Tac Toe — React Native

A mobile Tic Tac Toe game built with React Native and Expo,
with Firebase Authentication and a clean, responsive UI.

## ✨ Features

- 🔐 User registration and login
- ✅ Signup form validation
- 🔥 Firebase Authentication
- 👤 User profile
- 🎮 Tic Tac Toe gameplay
- 🏆 Score tracking
- 🔄 New game functionality
- 📱 Responsive mobile UI
- 🚪 Secure logout

## 🛠️ Tech Stack

- React Native
- Expo
- JavaScript
- Firebase Authentication
- React Navigation
- Expo Vector Icons
- Expo Blur

## 📱 Screens

- Login
- Signup
- Home
- Profile
- Game Board

## 🚀 Getting Started

### Clone the repository

git clone YOUR_REPOSITORY_URL

### Install dependencies

npm install

### Start the project

npx expo start

## 🔐 Firebase Setup

Create a Firebase project and configure Firebase Authentication.

Add your Firebase configuration to:

firebase.config.js
